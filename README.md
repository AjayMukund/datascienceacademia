# Data Science Academia — website

Static marketing site for **https://ajaymukund.github.io/datascienceacademia/** (GitHub Pages) plus the
Supabase-backed student/admin portal (`login.html`, `student/`, `admin/`).

The public pages are **generated**: edit the sources, run the build, publish the whole folder.
Do not hand-edit the generated `*.html` files at the root or in `courses/`, `programmes/`, `blog/`,
`codechamps/` — the next build overwrites them.

## Folder map

| Path | What it is |
|---|---|
| `src/pages/*.html` | Jinja2 page templates → built to `/<name>.html` (index, courses, programmes, codechamps, projects, testimonials, blog, about, contact, 404) |
| `src/templates/base.html` | shared `<head>` (SEO, Open Graph, fonts, JSON-LD organisation graph), nav + footer includes |
| `src/templates/partials/` | `nav.html`, `footer.html` |
| `src/templates/detail-*.html` | one template each for course, programme, blog post and Code Champs level pages |
| `src/templates/redirect.html` | legacy `course.html?id=…` style URLs → new static pages |
| `courses-data.js`, `programmes-data.js`, `blog-data.js`, `cc-levels-data.js`, `projects-data.js`, `testimonials-data.js` | **content** — plain JS object literals, read by the build (and by the portal) |
| `Company_Info.txt` | company facts (also used by the chat assistant) |
| `assets/img/` | generated WebP images (480/960/1600 px) + `manifest.json` with sizes |
| `assets/og/` | generated 1200×630 social-preview images |
| `assets/fonts/` | self-hosted variable fonts (Cormorant Garamond, Outfit, Fira Code) |
| `style.css`, `script.js` | design system + shared behaviour (script.js is also used by the portal pages) |
| `sw.js`, `manifest.json` | service worker (network-first HTML, stale-while-revalidate assets) and PWA manifest |
| `sitemap.xml`, `robots.txt` | generated by the build |
| `Website Images/`, `Intern Testimonials/`, `12 Month … Roadmap.png` | original source images (not referenced by pages) |
| `tools/` | build pipeline (see below) |
| `_legacy/` | zip backup of the previous site (Aug 2026) |
| `dsa_app/`, `social-automation/`, `pwa_icon_bundle/`, `splash/` | unrelated to the website build |

## Build

```bash
pip install -r tools/requirements.txt        # jinja2, json5, Pillow (once)

python tools/optimize_images.py              # when source images change → assets/img/*.webp + manifest.json
python tools/make_og.py                      # when titles/images change   → assets/og/*.jpg
python tools/build.py                        # ALWAYS after editing src/ or *-data.js → all pages, sitemap, robots
python tools/check_site.py                   # QA: titles, descriptions, h1, links, JSON-LD, alt text …
python tools/serve.py                        # preview at http://127.0.0.1:8765/
python tools/screenshot.py courses.html out.png [--mobile]   # headless Chrome screenshot for visual checks
```

`tools/fetch_fonts.py` re-downloads the fonts (only needed if the font set changes).

## Editing

- **A course / programme / blog post / Code Champs level / project / testimonial** → edit the matching
  `*-data.js` file, then `python tools/build.py`. New entries get their own static page and sitemap entry
  automatically. Add a new image to `Website Images/…`, run `optimize_images.py`, then reference the source
  path in the data file.
- **Page copy or layout** → `src/pages/<page>.html` (components are documented at the top of `style.css`).
- **Navigation, footer, head tags** → `src/templates/partials/` and `src/templates/base.html`.
- **Contact details, social links, opening hours, site URL** → the `SITE` dict at the top of
  `tools/build.py` (feeds the footer, contact page, JSON-LD, canonical URLs and sitemap).
- **Moving to a custom domain** → change `SITE["url"]`, add a `CNAME` file, rebuild, run `make_og.py`
  (the OG images print the domain).

## Deploy

Commit the whole folder — generated HTML included — to the GitHub Pages branch. `.nojekyll` is present so
folders such as `_legacy/` are served as-is. After deploying, submit `sitemap.xml` in Google Search Console.
